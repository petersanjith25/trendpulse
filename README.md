# TrendPulse

TrendPulse is a data analytics learning and project repository covering
Python foundations, NumPy, Pandas, data visualization, exploratory
data analysis (EDA), SQL, and spreadsheets.

## Repository Structure

- part1_python_foundations/ - Python fundamentals and practice
- part2_numpy_pandas/ - Data manipulation using NumPy and Pandas
- part3_visualization_eda/ - Data visualization and exploratory analysis
- part4_sql_spreadsheet/ - SQL queries and spreadsheet analysis

## Tools and Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- SQL
- Microsoft Excel

## Goal

Build practical data analytics skills through exercises, datasets,
and hands-on projects.

## Status

Learning and development in progress.
